PDF LIBRARY - GITHUB PAGES

Folder structure:
    index.html
    pdfs/
        2588 (1).pdf

IMPORTANT:
Place your actual PDF file inside the "pdfs" folder using exactly this filename:
2588 (1).pdf

If you rename the PDF, update the href in index.html.

For GitHub Pages:
1. Upload index.html and the pdfs folder to your repository.
2. Open Settings -> Pages.
3. Select Deploy from a branch.
4. Select main and / (root).
5. Save.

Anyone who can access the GitHub Pages URL can view and download the PDF.
